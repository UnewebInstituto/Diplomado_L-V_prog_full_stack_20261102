API

Una API (interfaz de programación de aplicaciones, por sus siglas en inglés) es un conjunto de funcionalidades y reglas integradas en un programa de software (la aplicación) que permiten interactuar con él mediante software, a diferencia de una interfaz de usuario pensada para personas. Una API puede verse como un contrato sencillo (la interfaz) entre la aplicación que la ofrece y otros elementos, como software o hardware de terceros.

En el desarrollo web, una API suele ser un conjunto de recursos de código (por ejemplo, métodos, propiedades, eventos y URLs) que un desarrollador puede usar en sus aplicaciones para interactuar con componentes del navegador web del usuario, con otro software o hardware de su equipo, o con sitios web y servicios de terceros.

Por ejemplo:

  • La API getUserMedia permite obtener audio y video de la cámara web del usuario, que luego queda a disposición del desarrollador para, por ejemplo, grabar video y audio, transmitirlos a otro usuario en una videoconferencia o capturar imágenes fijas del video.
  • La API de geolocalización permite obtener información de ubicación a partir de los servicios que el usuario tiene disponibles en su dispositivo (por ejemplo, GPS). Esa información puede combinarse con otros servicios, como las API de Google Maps, para marcar la ubicación del usuario en un mapa personalizado y mostrarle qué atracciones turísticas hay en su zona.
  • La API de animaciones web permite animar partes de una página web, por ejemplo, para mover o rotar imágenes mediante código.
